## Local development

```bash
pnpm install
pnpm dev
```

## Production

```bash
pnpm build
```

The Whop configuration is documented in `WHOP_SETUP.md`. The six program records intentionally ship without Whop product IDs/URLs so the wrong existing products are never reused by accident. Add the new Whop products before enabling enrollment.
